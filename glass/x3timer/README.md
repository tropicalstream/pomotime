# X3 Timer

Glanceable dual-mode timer: Pomodoro focus mode plus HIIT/Tabata, EMOM and
AMRAP athletic programs. Click starts/pauses, double-click resets, hold cycles
programs (guarded mid-session), nod extends/skips/laps, head left/right
switches programs. A running Pomodoro shrinks to a corner chip after 5 s idle.
