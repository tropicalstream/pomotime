# PomoTime

PomoTime is a glanceable dual-mode timer built as a native plugin for MemoMind smart glasses, running on the MemoMind Plugin Open Platform. It combines a Pomodoro focus timer with three athletic interval modes (HIIT/Tabata, EMOM, and AMRAP) in a single widget that occupies a small corner of the display while the rest of the transparent panel stays clear. The design leans entirely on cadence and motion rather than color, since the glasses' monochrome display carries no color and no audio: work and rest phases pulse at different speeds, a running Pomodoro shrinks to a small corner chip when idle, and head motion is deliberately ignored during an active session so an accidental glance never disturbs the clock.

## Controls

- Click — start a session, or pause/resume a running one
- Double-click — reset when idle; extend the Pomodoro, skip an interval, or add an AMRAP lap while running
- Hold — cycle to the next program (Pomodoro, HIIT, EMOM, AMRAP), with a confirm-to-switch guard while a session is active
- Head left/right — browse programs while idle
- With a paired accessory ring — LEFT/RIGHT to change program, UP to extend/skip/lap, DOWN to pin or unpin the corner chip
